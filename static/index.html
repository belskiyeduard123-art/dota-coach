Не видит твои матчи? Включи доступ (1 минута)
  1. Открой Dota 2 → Настройки (шестерёнка) → вкладка «Аккаунт».
  2. Включи «Открыть доступ к данным публичных матчей» (Expose Public Match Data).
  3. Сыграй один матч и подожди пару минут.
  4. Вернись сюда и нажми «Разобрать» снова.
