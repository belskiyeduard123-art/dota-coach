DOTA COACH — локальный запуск
==============================

САМЫЙ ПРОСТОЙ СПОСОБ (ключи задаются один раз)
-----------------------------------------------
1. Установить зависимости (один раз):
       python -m pip install flask requests

2. Настроить ключи ОДИН РАЗ:
   - Найди файл .env.example
   - Скопируй его и переименуй копию в .env  (просто ".env", без .example)
   - Открой .env блокнотом, впиши свой секретный ключ YandexGPT после
     YANDEX_API_KEY=    (без кавычек, без пробелов)
   - folder_id уже вписан, менять не нужно
   - Сохрани

3. Запускать сервер двойным кликом по файлу start.bat
   (браузер откроется сам через 3 секунды)

   Либо вручную:  python app.py

Всё. Ключи теперь подхватываются автоматически из .env — больше
не нужно вводить $env: каждый раз.

ВАЖНО про безопасность
----------------------
Файл .env с твоим ключом — НИКОМУ не показывай и не выкладывай в интернет.
Это твой секрет. .env.example можно показывать (там нет реального ключа).

СТРУКТУРА
  app.py            — бэкенд (логика + чтение ключей из .env)
  static/index.html — страница, которую видит пользователь
  .env.example      — шаблон для ключей (скопируй в .env)
  start.bat         — запуск двойным кликом (Windows)

ДАЛЬШЕ (выложить в интернет)
На хостинге ключи задаются в его настройках окружения, файл .env туда
не загружается. Код менять не нужно.
